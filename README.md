## The JavaScript Situation
Look, **I HATE JAVASCRIPT**. 
There is a `<script>` tag in the `index.html`. It's there. It works. **DO NOT MESS WITH THE SCRIPT.** 
It handles the mobile menu and fires a sneaky Discord webhook ping every time someone visits because why not. I still hate JS though. Pure CSS would have been better, but here we are.

## Spectacular Features
* **One Box Burger Menu:** It magically transforms into a mobile menu on phones and a normal top-bar menu on PCs. 
* **The Infamous Red Div:** A custom box that took a solid 10 minutes of pain and suffering to align and fix. It holds some premium useless text.
* **Epic Background:** Featuring a high-resolution view of outer space directly from NASA because plain black wasn't cosmic enough.
* **External Links:** Quick access to my GitHub, my Printables profile, and my other website (which is broken most of the time).
